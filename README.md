# pearl-z.com

Static site for GitHub Pages.

1. `python download_images.py` (once, on your computer, while Squarespace is still active)
2. Commit and push; in the repo go to Settings > Pages and publish from the main branch (root).
3. DNS: four A records on `pearl-z.com` -> 185.199.108.153 / .109.153 / .110.153 / .111.153, and a CNAME `www` -> `<your-github-username>.github.io`.
